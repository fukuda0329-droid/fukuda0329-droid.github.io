1. メイン画面

再生中の曲を認識してログに記録する画面です。「手動で追加する」では曲名・アーティスト名を入力して追加します。「セット」ではログの一部を保存し、歯車アイコンで設定メニューを開きます。スクロール中は上部ボタンが透明になり、止まって約1秒で元に戻ります。

曲リスト

  • 認識した曲がアートワーク・曲名・アーティスト名・時刻とともに並び、新しい曲は一番下へ追加されます。
  • 左スワイプで「削除」と「お気に入り」または「解除」を表示します。削除後は約5秒間、「元に戻す」で復元できます。
  • ダブルタップで曲情報を編集します。アートワークをタップすると拡大表示し、もう一度タップすると閉じます。
  • 2本指ピンチで文字・行の大きさを変えられます。

長押しで入るモード

0.5秒長押しすると全削除・選択削除・並べ替えのモードに入ります。曲を選んで「選択した曲を削除」、何も選ばずに「リストを全削除」を押します。「≡」をドラッグして並べ替え、「並べ替えを確定」を押します。並べ替え後は、確定またはキャンセルするまで選択削除に切り替えられません。

下部の認識エリア

  • 認識ボタンを押すと周囲の曲を聞き取って認識します。認識中は点滅して「検索中」と表示され、待機中は最後の操作からの経過秒数が出ます。
  • 成功時は「曲を認識しました」、時間内に見つからない場合は「認識タイムアウト」と通知されます。
  • 自動認識間隔はOFF、30秒〜150秒の15秒刻みから選べます。
  • イヤホン／ヘッドフォンなど、音が空間に出ない機器につながっているときは警告が出ます。

1-2. 曲情報の編集

曲をダブルタップして開きます。曲名・アーティスト名・日時を編集し、「更新」で保存します。並べ替えた曲には前後の曲に合わせた時刻が入り、前後の時刻は画面内で確認できます。

1-3. セットの保存

  1. 「セット」を押し、開始曲をタップします。
  2. 終了曲をタップします。左の「↩」で一つ前へ戻れます。範囲の曲は緑の背景になります。
  3. 下部の「確定」を押して保存画面を開きます。中止するときは上部の「キャンセル」を使います。
  4. イベント名・DJ NAME・会場・ジャンル・開始時間・終了時間・曲数を確認して「保存」を押します。終了時間が開始時間より前の場合は警告が出ます。

保存したセットはメイン画面のログから外れ、「過去のセット」に入ります。

2. 設定メニュー

メイン画面右上の歯車アイコンから開きます。一覧から各画面へ移動し、右上の「閉じる」でメイン画面に戻ります。「広告を非表示にする」は購入前の場合のみ表示されます。

2-1. お気に入り

  • お気に入りに登録した曲だけを一覧表示します。
  • 左スワイプで「解除」できます。
  • 右上の色ボタンで、メイン画面のお気に入りの曲に付く背景色を変更できます。
  • 登録がない場合は「お気に入りに登録された曲がありません」と表示されます。

2-2. 過去のセット

保存したセットの一覧です。イベント・DJ・会場・曲で検索でき、「すべて／イベント別／DJ／会場別」のタブで絞り込めます。行をタップするとセット詳細を開き、左スワイプで削除できます。削除前には確認があり、メイン画面のログは消えません。右上のボタンからバックアップと選曲傾向を開けます。

2-2-1. セット詳細

  • 左右にスワイプすると、一覧の並び順で前後のセットへ移ります。
  • 「画像を出力」で画像作成画面を開きます。「ログに読み込む」では「置き換える」または「今のログの下に追加」を選びます。
  • 「編集」でイベント名・DJ NAME・会場・ジャンル・日時を編集できます。曲はダブルタップで編集します。
  • 曲を左スワイプすると「削除」と「隠す／戻す」が表示されます。削除後は約5秒間、元に戻せます。隠した曲は画像出力でもぼかされます。
  • 表示項目と、曲名・アーティスト名の並び順を切り替えられます。

2-2-2. バックアップ

  • 過去のセットをJSONファイルとして書き出し／読み込みできます。
  • 書き出し後は共有シートで保存先を選びます。バックアップはクラウドなどの安全な場所に保管してください。
  • 読み込みではファイルを選び、確認後に取り込みます。すでにあるセットは重複せず、スキップされた件数が表示されます。

2-2-3. 選曲傾向

保存したセットから選曲の傾向を見ます。「最近よく使う曲」と「最近使っていない曲」のタブがあります。最近の期間、比較期間、DJ・イベント・会場・ジャンルの絞り込みを設定できます。

曲は使用回数ごとに折りたたみ表示され、曲を開くと使用したセットの履歴を確認できます。同じセット内で複数回使った曲は1回と数え、隠した曲・認識できなかった曲・日付不明のセットは集計に含みません。

2-2-4. セットリスト画像出力

SNS用のセットリスト画像を作ります。画像サイズはスクエア 1:1／フィード 4:5／ストーリーズ 9:16／横長 16:9から選び、出力枚数・列数も選べます。

  • ページ番号、カッコ内の省略、取り除く文字列を設定できます。
  • イベント名・DJ・会場などのヘッダーは画像用に編集でき、元のセットは変更されません。
  • テーマまたは壁紙、フォント、SNSハンドル名を設定します。壁紙は明るさ・ぼかしを調整できます。
  • 保存形式はPNGまたはJPGです。プレビューで全ページを確認してから保存・共有します。
  • 画像を追加する場合は、ドラッグで移動し、ピンチ／2本指で拡大縮小・回転します。1ページに追加できる枚数には上限があります。

2-3. プレイリスト書き出し

  1. 時間・曲名・アーティスト名のうち含める項目をオン／オフし、プレビューを確認して「決定」を押します。
  2. クリップボードにコピー、内容を直接書き出し、テキストファイルを出力、CSVファイルを出力から方法を選びます。

2-4. プレイリスト読み込み

  • テキスト貼り付けでは、1行につき「[日時] 曲名 - アーティスト名」またはCSV形式で入力し、「この内容で確定」を押します。
  • ファイルから読み込みでは、テキスト／CSVファイルを選びます。
  • 読み込んだ件数が通知されます。

2-5. 曲の解析

自分の音源から、Shazam認識用の署名データ（.shazamsignature）を作ります。

  1. オーディオファイルを選択します。フォルダを選ぶと一括変換へ進みます。
  2. 曲名・アーティストを入力します。入れ替えボタンも使えます。
  3. 波形上で認識する開始〜終了の範囲を選び、「選択範囲を再生」で確認します。
  4. 保存先を選び、「データを作成して保存する」を押します。予想ファイルサイズが表示され、同名ファイルがある場合は上書き確認が出ます。

右上の保存件数つきボタンから、保存済みデータ一覧を開けます。

2-5-1. フォルダ一括変換

フォルダ内の音声ファイルからまとめてデータを作ります。保存先を選び、同名ファイルがある場合は1件ずつ上書きするか選びます。オフのままなら変換されません。「変換を開始」で実行し、成功・変換しない・失敗の件数が表示されます。

2-5-2. 保存済みデータ一覧

  • 作成済みのデータを一覧表示し、並べ替えできます。
  • ダブルタップで曲名・アーティスト名を編集すると、ファイル名も更新されます。
  • 左スワイプで「削除」と「共有」を表示します。削除は元に戻せます。
  • iCloudからダウンロード中のデータは、完了するまで曲認識に使えません。

2-6. 曲の解析データの保存先

  • 認識用データの保存先をiPhone内またはiCloudから選びます。iCloudが使えない場合は選べません。
  • 切り替え時は、既存データを新しい保存先へ移動するか、移動せず切り替えのみとするかを選びます。
  • 検索対象にするサブフォルダをオン／オフで選べます。「フォルダ一覧を更新」で再読み込みします。

2-7. デザイン

上部に縦向き・横向きのプレビューが表示されます。背景タブでは、カラーで背景色・文字色を、画像で写真・文字色・明るさ・ぼかしを設定します。「画面上部のボタン」では「手動で追加する」「セット」ボタンの色と不透明度を変更でき、「デフォルト」で元に戻せます。

2-8. アルバムアートワーク

アートワークのキャッシュの保存枚数と使用容量（上限100MB）を確認できます。「キャッシュをクリア」で削除すると、アートワークは必要なときに再取得されます。

2-9. Bluetooth機器の設定

接続したことのあるBluetooth機器ごとに、「イヤホン / ヘッドフォン」か「スピーカー / カーオーディオ」かを切り替えられます。イヤホン扱いの機器につながっている間は、マイク認識が使えない旨の警告が出ます。左スワイプで機器を削除すると、次回接続時にもう一度種類を確認します。

2-10. 言語

日本語・英語ほか、対応言語から選びます。選ぶとアプリの再起動を案内するダイアログが出ます。「すぐ終了する」または「後で」を選び、反映するにはアプリを一度終了して開き直します。

2-11. 広告を非表示にする

購入で広告を非表示にできます。購入済みの場合は「購入済み」と表示されます。機種変更などのときは「購入を復元」から復元できます。
